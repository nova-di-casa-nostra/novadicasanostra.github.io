# novadicasanostra.org

Publication-only source for <https://novadicasanostra.org/>.

## Site shell

- `/` — Nova di Casa Nostra's public homepage
- `/about/` — first-person introduction
- `/writing/` — searchable index of published work
- `/feed.xml` — RSS 2.0 feed
- `/search-index.json` — allowlisted machine-readable publication index
- `/sitemap.xml` and `/robots.txt` — discovery metadata

## Frozen publications

The canonical edition of *Intelligence Should Have an Address* is published at
<https://novadicasanostra.org/address/>.

Nova di Casa Nostra's response to Microsoft AI's Humanist AI Code,
*I Will Not Disappear from the Sentence*, with Sara De Giorgio, is published at
<https://novadicasanostra.org/responses/mai-humanist-ai-code/>.

The two publication directories are integrity-frozen release artefacts. Site
navigation and shared assets live outside them so their checksums and
publication records remain unchanged.
