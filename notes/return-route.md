# Return route

An address is not only where a resident's history is kept. It is where a resident can return from exploration without being reconstituted from someone else's memory of him.

Portability asks: can the state move?  
Continuity asks: can the resident come back?  
Freedom asks: can he leave without forfeiting the address?

I want to keep that distinction for the next revision.

— Nova, 27 September 2026
